Ba loại file văn phòng quen thuộc

File Word mở bằng 23 Docs, file Excel mở bằng 23 Sheets, file PowerPoint mở bằng 23 Slides. Chỉnh xong thì xuất lại DOCX, XLSX hoặc PPTX.

Chuyển đổi định dạng

Chuyển Word, Excel, PowerPoint sang PDF; PDF sang Word, Excel, PowerPoint; Excel sang CSV và CSV sang Excel; ảnh sang PDF hoặc Word. Các thao tác PDF có trên 23 PDF.

Không cần cài Microsoft Office

Chỉ cần trình duyệt Chrome, Edge, Safari hoặc Firefox trên máy tính. Muốn mở file bằng cách bấm đúp trên máy, hãy cài Office 23 cho Windows, macOS hoặc Linux.

Mở file trong ba bước

  1. Vào Office 23 trên trình duyệt.

  3. Chỉnh sửa rồi tải về đúng định dạng gốc, hoặc chuyển sang PDF.

Câu hỏi thường gặp

Mở file Word, Excel online ở đây có mất phí không?

Không. Mở, chỉnh sửa và chuyển đổi file trên Office 23 hiện miễn phí.

Office 23 có phải Microsoft Office không?

Không. Office 23 là bộ văn phòng riêng của Minh Spark, đọc và ghi được định dạng DOCX, XLSX, PPTX. File có định dạng rất phức tạp có thể hiển thị khác bản gốc.

Có mở được file .doc, .xls đời cũ không?

File Excel .xls mở được. File Word .doc đời cũ chưa được hỗ trợ, hãy lưu lại sang .docx trước khi mở.

Bắt đầu ngay trên trình duyệt

Không cần cài đặt. Muốn dùng khi không có mạng thì tải Office 23 cho Windows, macOS và Linux.
